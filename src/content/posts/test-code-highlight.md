# 测试代码高亮

这是一篇测试文章，用于验证代码高亮功能是否正常工作。

## JavaScript 代码

```javascript
function hello() {
  console.log("Hello, world!");
}

hello();
```

## TypeScript 代码

```typescript
interface User {
  name: string;
  age: number;
}

const user: User = {
  name: "John",
  age: 30
};

console.log(user);
```
